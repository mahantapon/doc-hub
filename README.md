# Doc Hub — เรืองอนันต์

เว็บรวมเครื่องมือแก้ปัญหาการแปลงเอกสารระหว่าง Mango ERP กับ Google Workspace
ทำงานในเบราว์เซอร์ทั้งหมด (GitHub Pages) — ไฟล์ไม่ถูกส่งขึ้นเซิร์ฟเวอร์อื่น ไม่มีค่าใช้จ่าย

## เครื่องมือ

| แท็บ | ทำอะไร | แก้ปัญหา |
|---|---|---|
| 📊 แปลง Excel ⇄ Sheet | แปลงไฟล์ .xlsx จากระบบ ERP เป็น Google Sheet ทีละหลายไฟล์ (batch) และส่งออกกลับเป็น .xlsx | เอกสารแบบฟอร์ม/checklist จำนวนมาก |
| 📤 แปลง Sheet เป็นไฟล์ | วางลิงก์ Google Sheet → ได้ไฟล์ .xlsx / PDF ส่งต่อให้บุคคลภายนอก | ผู้รับภายนอกใช้ลิงก์ไม่สะดวก |
| 📄 สร้างเอกสาร (Template) | กรอกฟอร์ม (ชื่อคู่สัญญา/เลขที่/มูลค่า/วันที่) → ได้ .docx ฟอนต์/เลย์เอาต์ครบ 100% ตัวหนังสือบาทเติมอัตโนมัติ | เอกสารซ้ำ ๆ เช่นสัญญาว่าจ้าง — ไม่ต้องแก้มือทีละจุด |
| 📝 แก้ Word (100%) | เปิด .docx ไฟล์ไหนก็ได้ แก้ข้อความ แล้วดาวน์โหลดกลับโดย format ไม่เพี้ยนแม้แต่จุดเดียว | Word → Google Docs ฟอนต์/จัดหน้าเพี้ยน |
| 📖 วิธีใช้ / กติกา | SOP การใช้เอกสารของทีม | — |

## หลักการของแท็บแก้ Word

ไฟล์ .docx คือ zip ที่มี XML ข้างใน — เว็บนี้แก้เฉพาะข้อความใน `<w:t>` ของไฟล์เดิม
ไม่มีขั้นตอน convert ไฟล์เลย ส่วนที่ไม่ได้แก้ถูกเก็บ byte เดิมไว้ทั้งหมด
ดังนั้นฟอนต์ / การจัดหน้า / ตาราง / หัวกระดาษ คงเดิม 100% เสมอ

## รันทดสอบในเครื่อง

```bash
python3 -m http.server 8090 -d .
# เปิด http://localhost:8090
```
